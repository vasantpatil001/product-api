# Product Management REST API

A secure Product Management REST API developed using Spring Boot, Spring Data JPA, Hibernate, MySQL, Spring Security and JWT authentication.

## Features

- Product CRUD operations
- Item CRUD operations
- Product and Item relationship
- JWT-based authentication
- Refresh token support
- Role-based authorization (USER / ADMIN)
- Input validation
- Global exception handling
- RESTful APIs
- MySQL database
- Docker and Docker Compose support
- Stateless security
- Pagination support
- Swagger / OpenAPI documentation
- Unit and integration testing

## Technologies Used

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- JWT
- Maven
- Docker
- Docker Compose
- Postman
- Swagger / OpenAPI
- JUnit
- Mockito
